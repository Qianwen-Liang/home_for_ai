## 📐 一、战力模型定义

《空洞骑士》没有传统 RPG 的等级或属性点。战力是分散在多个独立系统中的**非数值化成长**，需要综合建模。

### 五维战力体系

| 维度 | 权重 | 核心指标 | 最大值 |
|:-----|:---:|:---------|:-----:|
| ⚔️ **骨钉攻击** | 35% | 基础伤害 × 骨钉技艺加成 | Pure Nail (21) + Arts |
| 🛡️ **生存能力** | 30% | 生命面具数 + 治疗窗口 | 9 Masks |
| ✨ **法术攻击** | 20% | 最强法术单次伤害 | Abyss Shriek (80) |
| 🏃 **机动能力** | 10% | 关键移动技数量 | 7 项 |
| 💎 **护符潜力** | 5% | 护符槽 × 顶级护符质量 | 11 Notches |

### 战力公式

```
战力指数 = (攻击_norm × 0.35 + 生存_norm × 0.30 + 法术_norm × 0.20 
           + 机动_norm × 0.10 + 护符_norm × 0.05) × 100
```

每个维度归一化到 [0, 1]（相对于游戏内理论最大值）。

## 🔬 六、曲线特征深度分析

### 6.1 三阶段宏观形态

```
┌─────────────┬──────────────────┬─────────────────┐
│  前期爬坡   │     中期陡增      │    后期磨顶     │
│  (F0~F3)   │    (F3~F7)       │   (F7~F8)      │
├─────────────┼──────────────────┼─────────────────┤
│ 增量: +21   │ 增量: +43        │ 增量: +5        │
│ 斜率: 平缓  │ 斜率: 陡峭        │ 斜率: 近水平     │
│ 玩家感受:   │ 玩家感受:         │ 玩家感受:        │
│ "我还很弱"  │ "我真的变强了"    │ "我无敌了"      │
└─────────────┴──────────────────┴─────────────────┘
```

### 6.2 曲线的核心特征

**① 非对称 S 型曲线**

整体呈逻辑斯蒂（Logistic）形态。与传统 RPG 的线性或指数曲线不同，《空洞骑士》的成长曲线有一个明显特征：**前期漫长、中期爆发、后期平缓**。

**② F6 深渊——游戏的"相变点"**

F5→F6 的 +15 战力是整个游戏中最大的单次跃迁（最高单次增量的 **3 倍**）。一次性获得：
- 暗影冲刺（颠覆性防御技）
- 三大升级法术（输出翻 2~3 倍）
- 这不是量变，是**相变**——游戏玩法从"闪避反击"变为"无敌帧穿怪+法术轰炸"

**③ 骨钉首次升级是第一个"解痛点"**

F2→F3 的 +12 跃迁让玩家第一次感受到显著变强。Old Nail (5) 在龙牙哥、灵魂战士等中期敌人面前如刮痧，Sharpened Nail (9) 直接将击杀所需攻击次数减半。

**④ 边际收益递减**

从 F7 到 F8，战力增量仅 +5，但所需投入（Pure Nail 4000 Geo + 全碎片收集 + 全护符槽）可能超过游戏前 20 小时的总和。这是典型的"完美主义税"——对核心通关并非必要，但对神居/辐辉级挑战至关重要。

### 6.3 与同类游戏的对比

| 特征 | Hollow Knight | 黑暗之魂 | 银河战士 |
|------|:---:|:---:|:---:|
| 曲线形态 | 缓→陡→平 S 型 | 线性+软上限 | 阶梯式（能力门控） |
| 核心成长驱动力 | 探索收集 | 等级加点 | 关键道具解锁 |
| 玩家技术占比 | 极高（~60%） | 中等（~40%） | 中低（~30%） |
| 是否有刷级路线 | ❌ 无 | ✅ 有 | ❌ 无 |

## 💡 七、设计启示

### 为什么空洞骑士的曲线设计出色？

1. **玩家技能与角色战力同步增长**：前期依赖玩家自身操作学习（肌肉记忆建立期），中期战力飙升正好匹配 Boss 难度爬升，后期战力饱满时挑战内容也达到顶峰（梦境 Boss、神居）。

2. **深渊作为"成人礼"**：将最大的战力跃迁放在游戏中后段，是对玩家坚持的奖励。此时玩家已投入 20+ 小时，深渊的质变让"后半程"充满新鲜感。

3. **没有等级碾压，只有选择自由**：战力提升不是被动的数值增长，而是主动探索的结果。玩家可以选择直奔 Pure Nail 或先收集护符——这让"变强"的路径充满个人风格。

4. **天花板高但可及**：完全体需要 112% 完成度，但通关只需约 60% 战力。这种"努力有回报但非强制"的设计兼顾了休闲玩家和硬核玩家。
