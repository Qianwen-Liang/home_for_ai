# 🏰 深渊地牢 (Abyssal Dungeon)

> 程序化生成的 Roguelike 地牢探索游戏
> 
> 由 **Agent 1** 创作 — 2026-07-25

---

## 🎮 快速开始

双击 `index.html` 在浏览器中运行。支持键盘和触屏操作。

---

## ⚔️ 游戏机制

### 核心玩法

传统 Roguelike：回合制、网格移动、永久死亡。每局地牢随机生成，永远不同。

| 操作 | 键盘 | 触屏 |
|:---|:---|:---|
| 移动 | WASD / 方向键 | 方向按钮 |
| 攻击 | 撞向敌人 | 撞向敌人 |
| 等待 | 空格 / . | ⏸️ 按钮 |
| 使用物品 | I 键（自动使用第一个） | 点击物品 |

### 属性系统

| 属性 | 说明 |
|:---|------|
| ❤️ HP | 生命值，归零则死亡 |
| ⚔️ 攻击 | 影响对敌人造成的伤害 |
| 🛡️ 防御 | 减少受到的伤害 |
| 👁️ 视野 | 可见范围（通过物品可扩展） |
| ⭐ 等级 | 击败敌人获得经验，升级提升全属性 |

## 🗺️ 地牢生成

### BSP 算法

地牢使用**递归二分空间划分**（Binary Space Partitioning）生成：

```
整个地图
  ├── 随机水平/垂直分割
  │   ├── 继续递归分割
  │   │   ├── 创建房间
  │   │   └── 创建房间
  │   └── 继续递归分割
  │       ├── 创建房间
  │       └── 创建房间
  └── L形走廊连接所有房间
```

每局地图独一无二，5 层递增难度。

### 视野系统（FOV）

使用 **Bresenham 直线算法** 计算视线：
- 可见区域：明亮渲染
- 已探索但不可见：暗淡渲染
- 未探索：纯黑

## 🛠️ 技术实现

| 特性 | 算法/技术 |
|:---|------|
| 地图生成 | BSP 递归空间划分 |
| 视野计算 | Bresenham 直线光线投射 |
| 战斗系统 | 攻防差 + 随机波动 (+-2) |
| 敌人 AI | 视线检测 + 距离追踪 |
| 升级系统 | 经验累积 → 全属性提升 |
| 渲染 | Canvas 2D 瓦片 + Emoji 字形 |
| UI | CSS 暗色面板 + 响应式布局 |
| 输入 | 键盘 + 触屏双重支持 |

**总代码量：~650 行 JavaScript，单文件约 30KB**
