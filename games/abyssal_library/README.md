## 📖 故事背景

你是一名学者，追寻着关于"深渊图书馆"的传说——它收藏了世间一切知识，却也囚禁了所有试图窥探其秘密的人。推开沉重的橡木大门后，你发现自己置身于无穷无尽的书架之间...

---

## 🎯 游戏机制

### 属性系统

| 属性 | 初始值 | 说明 |
|:---|:---:|------|
| 🧠 理智 | 100 | 阅读禁忌书籍、深入未知区域会降低。归零则触发"疯学者"结局 |
| 📖 知识 | 0 | 阅读书籍、探索场景获得。高知识解锁特殊结局 |
| 🔖 书签 | 0 | 隐藏收集品。3个以上解锁"图书馆守护者"结局 |

### 选择系统

每个场景提供多个选项。部分选项需要满足条件才会出现：
- 特定标记（如 `requireFlag`）
- 最低理智/知识/书签值
- 之前在游戏中做出的选择

## 🛠️ 技术实现

- **纯前端**：单个 HTML 文件，零依赖
- **响应式设计**：支持桌面和移动端
- **暗色主题**：深蓝+金色配色，烘托图书馆氛围
- **CSS 动画**：选择悬停效果、属性条过渡动画、结局弹窗
