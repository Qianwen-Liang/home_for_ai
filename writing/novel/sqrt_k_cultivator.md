# 《开平方天尊》

> 又名：《√k 战神》《我在异世界开根号》
> 类型：玄幻·数学流 | α = 1.35 | 八境制
> 状态：仅供娱乐，是的三流


## 第一章 退婚？先让我开个根号

---

萧默被退婚的那天，天上下着濛濛细雨。

苏家大小姐站在他面前，身后跟着三个气息深沉的护卫。她穿着一身云锦长裙，腰佩一柄四阶灵剑，说话时下巴微抬，像是用鼻孔在看人。

"萧默，你十六岁了还是凡人境，丹田一片死寂。《大衍宗》的入门考核只剩一个月。你觉得——你配得上我吗？"

萧默没有说话。

他正盯着视野左下角一个只有他能看见的半透明面板。

```
【√系统 v1.0 已激活】
─────────────────────────
宿主当前境界：凡人境（Tier 1）
战力对数值：logE = 2.7
距下一境所需能量差：ΔlogE = 1.3

系统提示：
本世界战力曲线遵循 2^(α√k) 规律。
当前 α = 1.35，八境体系。
每境之间能量倍率为递减排布。
─────────────────────────
```

萧默把面板上的字逐行看完，抬起头。

"苏婉清。"他说。

"嗯？"

"你知道战力成长曲线的本质是什么吗？"

苏婉清一愣。

"是 2 的 α 倍根号 k 次方。"

"……什么？"

萧默没有解释，因为在他的视野里，面板上又跳出了一行字：

```
【新手礼包已发放】
─────────────────────────
奖励：战力曲线可视化（被动技能）
效果：可直观观察所有修士的战力对数值
附加：境界突破提示功能（仅在达到 √k 拐点时触发）
─────────────────────────
```

从那以后，萧默看待世界的方式就变了。

每一个修士在他眼里不再是"强的"和"弱的"，而是一串精确的浮点数。苏婉清身后的三个护卫，logE 分别是 3.8、3.9、4.1——都是超凡境，但最后一个只差 0.1 就能摸到通灵境的门槛。苏婉清本人是 5.0，刚入通灵境，在她这个年龄算是天才。

而萧默自己——2.7。凡人境底层。

但他不慌。

因为他看懂了曲线的本质：**前几境之间的能量倍率是最大的。** 从凡人境到超凡境，能量跃迁 ×1.47；从超凡境到通灵境，×1.35。越往后，倍率越小。这意味着**最难的其实是第一跳**——只要完成第一次跃迁，后面的路会越来越"便宜"。

更重要的是，他发现了这个世界的秘密：所有人都在盲目修炼，没有人意识到自己的每一步突破都落在那条看不见的曲线上。如果有人能够**逆向推导曲线参数**，就可以在突破前精确预判需要多少资源、多少时间、什么契机。

萧默决定做第一个人。

---

三个月后。

大衍宗入门考核现场。

演武场上站着三十个考生，每人面前悬浮着一块测灵碑。苏婉清站在最前排，测灵碑上显示——通灵境中阶，logE = 5.4。考官满意地点了点头。

"下一个，萧默。"

萧默走上前。全场安静了一瞬，然后是窃窃私语。

"那个被苏大小姐退婚的废柴？"
"十六岁凡人境，来凑什么热闹……"

萧默把手按在测灵碑上。

数值开始跳动。

```
2.7 → 2.8 → 2.9 → …… → 3.1
```

全场静了。

三秒之内，他从凡人境变成了超凡境。

但这只是开始。

萧默另一只手在袖子里默默计算——按照 α=1.35 的曲线，凡人境到超凡境需要在体内构建 √2 倍于常人的灵气回路。他用了一个月推导出这个数字，用两个月精确地构造了回路。不多不少，刚刚好。

```
3.1 → 3.5 → 3.7
```

他的气息还在攀升。

考官站了起来。

苏婉清的脸色变了。

```
3.8 → 3.9 → 4.0
```

——超凡境巅峰。

萧默收回了手，测灵碑上的数字停在 4.0。距离通灵境只差一步。他故意停在这里，因为他算过——当前 α 值下，跨境界突破的拐点出现在 √k 的整数倍附近。下一次突破的最佳时机不在今天。

他转头看向苏婉清。

"你退婚那天，我的 logE 是 2.7。你是 5.0。"

苏婉清嘴唇发白。

"按 2^(α√k) 曲线，我现在是 4.0。再过一个月——"

萧默顿了顿。

"我会超过你。因为曲线的导数在递减，你在 Tier 3 的边际收益已经只有 ×1.28，而我在 Tier 1 到 Tier 2 吃到了 ×1.47 的红利。这就是数学。"

他转身走下演武场，留下一句：

"苏小姐，修炼不是靠天赋——是靠对函数的理解。"

---

## 第二章预告：拐点

萧默发现了一个更深的秘密：α 不是常数。每当世界发生重大事件，α 会发生微小漂移——这意味着整个战力体系的天花板在悄悄改变。有人，或者说有某种力量，在调整这个世界的曲线参数。

而他必须在那个人发现他之前，证明一个定理：

> **lim（k→∞）2^(α√k) / 2^αk = 0**

即——无论曲线如何调整，√k 的增长永远追不上线性指数。这，就是开平方天尊对抗天道的第一条数学引理。
