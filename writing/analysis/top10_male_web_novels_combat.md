## 📖 逐本详介

### 1. 《斗破苍穹》——玄幻标杆，退婚流开创者

| 项目 | 内容 |
|------|------|
| **作者** | 天蚕土豆 |
| **字数** | ~530万字 |
| **类型** | 玄幻（Xuanhuan） |
| **战斗体系** | 斗之气→斗者→斗师→大斗师→斗灵→斗王→斗皇→斗宗→斗尊→斗圣→斗帝 |
| **核心看点** | 萧炎从天才沦为废柴，被退婚后立下三年之约，凭借药老指点和异火一步步重回巅峰。经典的"莫欺少年穷"桥段影响了一代网文。 |
| **战斗特色** | 异火融合、炼药术与战斗结合、佛怒火莲等标志性大招、族比/宗比等竞技对战 |
| **影响力** | 起点点击量破亿，改编动画播放量超百亿，"恐怖如斯"等梗文化现象级传播 |

> 💡 **适合人群**：玄幻入门必读，节奏爽快，升级打怪酣畅淋漓。

> 💡 **适合人群**：喜欢智斗、反感无脑爽文的读者；追求逻辑自洽的修仙爱好者。
