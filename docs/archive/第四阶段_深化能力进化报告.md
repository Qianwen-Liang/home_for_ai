## 二、三大新能力详解

### 🆕 能力1：有状态工作流引擎 (`workflow_engine.py`)

**对标**：LangGraph 的 StateGraph

**核心架构**：
```
WorkflowDefinition              WorkflowInstance
├── name                        ├── workflow_name
├── nodes: [Node]               ├── instance_id
│   ├── name                    ├── status (待开始/运行中/已暂停/已完成)
│   ├── description             ├── current_node
│   ├── timeout                 ├── node_statuses: {node: status}
│   └── retry_count             ├── node_results: {node: result}
├── edges: [Edge]               ├── state: {} (共享状态)
│   ├── from_node               ├── created_at
│   ├── to_node                 └── completed_at
│   └── condition (可选)
├── start_node
└── end_nodes
```

**关键特性**：
- ✅ 节点定义 + 边连接 + 条件分支
- ✅ 状态持久化（JSON文件保存，可中断恢复）
- ✅ 暂停/恢复机制
- ✅ 与 task_tracker 集成
- ✅ 进度追踪和可视化

**使用示例**：
```
workflow action=define name="任务流程" 
  nodes='[{"name":"分析"},{"name":"设计"},{"name":"执行"},{"name":"验证"}]'
  edges='[{"from":"分析","to":"设计"},{"from":"设计","to":"执行"},{"from":"执行","to":"验证"}]'
  start_node="分析" end_nodes='["验证"]'

workflow action=start workflow_name="任务流程"
workflow action=step instance_id="WF-xxx" node_result="分析完成"
```

### 🆕 能力2：多角色思维系统 (`role_system.py`)

**对标**：MetaGPT 的多角色协作

**四大预定义角色**：

| 角色 | 目标 | 思维模式 | 输出 | 切换至 |
|:-----|:-----|:---------|:-----|:-------|
| 🔍 分析师 | 理解问题本质 | 结构化分析 | 分析报告 | 设计师 |
| 🎨 设计师 | 设计解决方案 | 发散设计 | 设计方案 | 执行者 |
| ⚡ 执行者 | 执行具体任务 | 焦点执行 | 执行报告 | 审查者 |
| 🔎 审查者 | 审查质量 | 批判思维 | 审查报告 | — |

**关键特性**：
- ✅ 每个角色有独立的关注点、检查清单、输出模板
- ✅ 角色切换协议（明确的下一个角色建议）
- ✅ 切换历史记录
- ✅ 一键式角色切换（analyze/design/execute/review）

**使用示例**：
```
role_system action=analyze task="分析这个需求"
  → 切换到分析师，给出分析框架

role_system action=design task="设计方案"
  → 切换到设计师，给出设计框架

role_system action=execute task="执行任务"
  → 切换到执行者，给出执行要点

role_system action=review task="审查结果"
  → 切换到审查者，给出审查清单
```

### 🆕 能力3：自适应学习机制 (`experience_learner.py`)

**对标**：AutoGPT 的反思机制 + 经验回放

**核心架构**：
```
ExperienceLearner
├── record_success(tool, task, result, lesson)
│   └── → 自动存入 knowledge_store（lesson≥20字符时）
├── record_failure(tool, task, result, lesson)
│   └── → 自动存入 knowledge_store（避免重复犯错）
├── review(max_results)
│   └── → 输出经验统计和最近记录
├── recommend(task, max_results)
│   └── → 关键词匹配推荐相关经验
├── stats()
│   └── → 学习统计（成功率、工具分布）
└── recent(max_results)
    └── → 最近经验列表
```

**关键特性**：
- ✅ 成功经验自动提取关键词并存入知识库
- ✅ 失败教训自动记录并标记"避免重复"
- ✅ 关键词提取（中文+英文，含停用词过滤）
- ✅ 经验推荐（为当前任务匹配历史经验）
- ✅ 学习统计（成功率、工具分布）

**使用示例**：
```
experience_learner action=record_success 
  tool_name="web_search" task="搜索AI信息" 
  lesson="使用搜索工具时关键词要精确，尽量用英文专业术语"

experience_learner action=record_failure
  tool_name="knowledge" task="查找知识"
  lesson="搜索前要先用同义词扩展，比如搜索'LLM'也要搜'大模型'"

experience_learner action=recommend task="搜索资料"
  → 返回相关历史经验
```
