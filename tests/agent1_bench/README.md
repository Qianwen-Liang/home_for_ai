# Agent1-bench — 可复现能力评测基准

Agent 1 自建的编码/自治能力基准，对标 SWE-bench 的"任务 → 解答 → 测试验证"模式，
为自我进化提供可量化、可复现的标尺。

## 设计目标

1. **可复现**：任务集固定，评分自动化，任何时刻运行得到一致结果。
2. **可量化**：输出通过率、分类通过率，为进化前后对比提供数据。
3. **对齐六层指标**：任务覆盖 L1/L2/L3/L5 能力维度。

## 目录结构

```
tests/agent1_bench/
├── README.md        # 本说明
├── scorecard.json   # 六层打分卡（基线数据）
├── runner.py        # 基准运行器（自动评分）
├── gen_tasks.py     # 任务生成脚本（生成 20 个任务）
├── answers.py       # 答题脚本（应用基线解答）
├── results.json     # 最近一次运行结果
└── tasks/           # 20 个任务文件（含测试）
```

## 使用方法

```bash
# 生成任务（骨架/含 bug 代码）
python -X utf8 tests/agent1_bench/gen_tasks.py

# 答题（将解答应用到任务）
python -X utf8 tests/agent1_bench/answers.py

# 评分
python -X utf8 tests/agent1_bench/runner.py
```

## 任务分类

| 维度 | 任务 | 数量 |
|------|------|------|
| L1-代码生成 | 算法实现 | 4 |
| L2-诊断修复 | Bug 修复 | 4 |
| L2-重构 | 代码结构改善 | 4 |
| L3-数据处理 | 实用编码 | 4 |
| L5-健壮性 | 防御编程 | 4 |

## 基线（2026-08-15）

- **通过率：20/20 (100%)**
- 各维度均为 100%

### ⚠️ 诚实评估

v1.0 任务偏基础（简单/中等难度），基线 100% 仅表示**基础编码能力达标**，
尚不足以区分"进化提升"。后续（P4 阶段）需增加**困难级任务**形成能力梯度，例如：
- 复杂算法（动态规划、图算法）
- 多文件协同重构
- 并发/异步处理
- 真实场景 bug（跨模块依赖）
- 性能优化任务
